# Страница оформления заказа

---

## Отображение тарифов на чекауте

На странице оформления заказа в методах доставки появляется список тарифов, включённых в настройках плагина.

**Условия отображения тарифов:**
- Тарифы должны быть доступны для вашего договора со СДЭК
- Параметры отправления (направление, вес, габариты) должны соответствовать возможностям тарифа
- В полях **city** (город) и **postcode** (почтовый индекс) должны быть введены корректные данные

---

## Выбор пункта выдачи (ПВЗ)

Для тарифов с доставкой **до склада** (ПВЗ СДЭК) отображается кнопка **«Выбрать ПВЗ»**.

<Image img={require('./img/checkout_tafiffwarehouse.png')} />

При нажатии на кнопку открывается карта для выбора пункта выдачи.

<Image img={require('./img/checkout_mappvz.png')} />

:::warning
**Важно:** при выборе доставки до склада или постамата выбор пункта получения **обязателен**. Система не позволит создать заказ без выбора ПВЗ на карте.
:::

---

## Регистрация заказа в СДЭК

После создания заказа с доставкой СДЭК на его детальной странице в панели администратора появляется блок для отправки заказа в систему СДЭК.

**Чтобы отправить заказ:**
1. При необходимости укажите габариты упаковки (если рассчитанные автоматически не подходят)
2. Нажмите кнопку **«Отправить»**

<Image img={require('./img/create_order.png')} />

---

## Управление отправленным заказом

После успешного создания заказа в системе СДЭК в блоке **«Метод доставки CDEK»** появляется информация о накладной и кнопки управления:

<Image img={require('./img/create_order_sucsessful.png')} />

### Получение накладной

При нажатии на кнопку **«Получить накладную»** формируется печатная форма квитанции (PDF-файл), который автоматически открывается для скачивания.

### Удаление заказа

При нажатии на кнопку **«Удалить заказ»** заказ удаляется из системы СДЭК.

**Особенности:**
- Информация об удалённом заказе сохраняется в блоке до создания следующего
- Под блоком появляется кнопка **«Пересоздать»**, которая возвращает к изначальной форме создания заказа

<Image img={require('./img/delete_order.png')} />

## Важное ограничение

:::note
В текущей версии плагина **нет функционала вызова курьера** для забора груза.
:::

При выборе тарифа с режимом доставки **«от двери»** заявка на вызов курьера не формируется автоматически.

**Рекомендации:**
- Оформляйте забор груза через личный кабинет СДЭК
- Обратитесь к закреплённому менеджеру СДЭК для формирования заявок на забор груза по заказам с режимом доставки «от двери»
